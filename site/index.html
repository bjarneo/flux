14:07 Codex waits for an answer.

The Inbox shows the agent that waits first. It shows the question, and the command that each choice approves. Tap 1, and Flux types the answer into the herdr pane on the computer.

Agent replies need agent control on the computer, and the phone unlock.

14:09 Read the output before you answer.

Open the agent to see its terminal output in color. Select Changes to review the diff of the working tree. Then answer from the same screen, or type a message to the agent.

14:22 sudo asks for your fingerprint.

A sudo prompt on the computer shows on the phone. Touch the fingerprint sensor to approve it. The iPhone uses Face ID or Touch ID, and the Mac uses Touch ID.

Only root on the computer can change the key that checks the approval. If the approval fails or times out, sudo asks for the password.

~sudo flux-cli approve setup

15:40 Copy on the phone, paste on the computer.

Flux sends clipboard text and images in both directions. Send files, photos, and links from the Share menu of any app. Away from home, Flux connects through Tailscale.

16:12 Get a file from the computer at home.

Get files opens the shared folders of the computer, read-only. Search all of them by name, then save the file on the phone.

17:30 Pause the music at home.

Media shows what plays on the computer. Play, pause, skip, seek, and set the volume. The Inbox also shows what plays now, with play and pause.

18:02 Move a window to another workspace.

The Omarchy panel shows your workspaces and the focused window. Move, close, or float a window. Open the Omarchy menu, a terminal, or a browser with their key bindings.

18:34 At the desk, the phone is a touchpad.

Use the phone as a touchpad and keyboard, a webcam, or a microphone. Show the computer screen on the phone, with its audio. The Flux window on the computer shows what is live, with Stop.

18:51 Find the phone.

Ring it from the Flux window, or run the command below. Tap I found it to stop the ring.

~flux-cli ring

The screens show Flux for Android 0.12.0 in demo mode, with sample computers and agents.

On the computer, Flux is a window.

The Flux window shows each device with its battery, its notifications, and what is live. flux-cli does the same from a terminal or a script. In omarchy-shell, the Flux mark in the bar opens the window.

~flux-cli open

Flux takes the theme of your Omarchy.

The computer sends its active theme to the phone. Change the theme, and the phone changes with it. A contrast check keeps the text readable in every theme.

Tokyo Night is the default when the computer sends no theme.

You pair with a key that you can see.

Compare 16 characters.
Pairing shows the same key on both screens, for example 5EE6 825F 974E D59A. Accept only when every character matches. A pairing that the computer starts also needs a confirmation on the computer.
Add no firewall rule.
fluxd opens the connections to the phone itself. Flux works with the default Omarchy firewall, which blocks inbound traffic.
Choose what each device can do.
Turn clipboard, notifications, shared folders, remote input, remote desktop, and agent control on or off for each device.
Unlock the phone for control.
Agent replies and remote desktop ask for the phone lock first. The unlock stays valid for 5 minutes.

Install Flux on both sides.

1 On Omarchy

~yay -S omarchy-flux
~flux-cli setup
~flux-cli open

To build from source, read the install guide. To update later, run flux-cli update.

2 On the phone or the Mac

Android

Android 10 or later

Download the APK

The computer sends later versions to the phone.

iPhone

iOS 17 or later

Build with Xcode

A free Apple ID works. The app then runs for 7 days.

Mac

macOS 14 or later

Download for Mac

The app is not notarized. Before the first start, run xattr -dr com.apple.quarantine Flux.app.

3 Pair them

Open Flux on both sides. Select + Pair new device in the Flux window, and compare the key on both screens.
